# CDLD-LoS — Length-of-stay prediction using physician latent traits

![CDLD-LoS overview](graphical_abstract/20261004_graphical_abstract.png)

[SVG](graphical_abstract/20261004_graphical_abstract.svg) · [Python source](graphical_abstract/20261004_graphical_abstract.py)

Code for the paper *"Length-of-stay prediction using physician latent traits"*
(under review).

In MIMIC-IV the admitting physician exists only as a de-identified identifier —
there are **no observed physician attributes**: no specialty, no seniority, no
case-mix descriptor. This repository discovers a latent representation of each
physician **from interaction records alone**, using cyclic dual latent discovery
(CDLD), and combines it with 54 admission-time patient features to predict
length of stay.

Korean version: [README.ko.md](README.ko.md)

## What we found

| What the model uses | RMSE (days) | R² | Prolonged-LoS AUROC |
|---|---|---|---|
| Nothing (global mean) | 4.496 | 0.000 | 0.500 |
| **Physician identifier only** (historical mean LoS, no model fitting) | **4.302** | **0.085** | 0.674 |
| 54 patient features | 4.387 | 0.048 | 0.686 |
| Patient features + physician historical mean | 4.300 | 0.085 | 0.710 |
| Patient features + shrunk physician historical mean | 4.296 | 0.087 | 0.710 |
| **Patient features + physician latent traits** | **4.270** | **0.098** | **0.717** |

CDLD learns physician representations from interaction records and combines them
with admission-time patient features to predict length of stay. Adding physician
latent traits reduced RMSE from 4.387 to 4.270 days and increased R² from 0.048
to 0.098.

The physician's historical mean LoS alone achieved lower RMSE than the
patient-feature model: 4.302 versus 4.387 days. Adding the **shrunk physician
historical mean** to patient features reproduced 0.090 days (77%) of the
0.117-day RMSE improvement. CDLD provided a further 0.027-day reduction relative
to that comparator (p < 0.001, same direction in all five folds). These paired
contrasts use unrounded run-level values.

In the diagnostic model containing both latent representations, shuffling
physician latent traits increased RMSE by 0.192 days, compared with 0.003 days
for patient latent traits. In the patient stratum with no training records,
shuffling changed RMSE by −0.005 days: patient latent traits provided no observed
improvement there. The observed patient–physician differences support the
asymmetric predictor: observed features for patients and latent traits for
physicians. Record count and entity characteristics were not separated in this
comparison.

> Numbers above are from the 5-fold run reported in the paper. They are
> regenerated by `cdld_los.ipynb`; see `tables/p_table2.csv` after a run.

## Getting the data

You do **not** need all of MIMIC-IV. Only three files from the `hosp` module:

```
MIMIC_DIR/
  admissions.csv.gz          # admit/discharge times, admission type and route,
                             # demographics, admit_provider_id
  patients.csv.gz            # sex, age
  omr.csv.gz                 # blood pressure, body measurements
```

MIMIC-IV v3.1 is available from PhysioNet and requires credentialing plus a
signed data use agreement. **Neither the raw files nor any derived cache may be
redistributed**, the repository instead provides code, saved notebook outputs and the graphical abstract.

Note that `diagnoses_icd` is deliberately **not** used. Diagnosis codes are
assigned at discharge, so using them would leak the outcome. This makes the task
an admission-time prediction and means the R² here is not comparable to studies
that use data recorded during the stay.

## What is not in this repository

MIMIC-IV cannot be redistributed under the PhysioNet data use agreement, and
neither can data derived from it at record level. Two files produced by the
notebook — the per-admission actual and predicted length of stay used for the
scatter plot — are therefore kept out of this repository, together with the
raw files and the parquet cache. A `.gitignore` enforces this.

The notebook includes saved experimental result tables and analysis figures,
which can be inspected without MIMIC credentials. Recomputing them from the
original data requires credentialed access to the three files listed above.
The literature-review table and conceptual diagrams are not generated by the
experiment notebook.

### Running the paper notebook

1. Put the three files above in `MIMIC_DIR` (set at the top of the constants cell).
2. Run all cells. A full run is roughly 2–4 hours on one GPU (RTX 4090).
   The first run builds a parquet cache; later runs reuse it.
3. To run in pieces, enable `RUN_MAIN` → `RUN_BASELINE` → `RUN_DIAG` →
   `RUN_FAIRNESS` in that order — the last three read latent traits and splits
   saved by the first.
4. `QUICK = True` runs fold 0 only. Useful for checking the pipeline; not the
   numbers in the paper.

To regenerate results from an existing local run after a kernel restart:

1. Run Setup, paths/constants and progress cells.
2. Run **Significance tests**, then **Build the paper tables**. These read the
   saved CSV files in `tables/`, including `p_main.csv` and `p_aux.csv`.
3. Run **Figures** with the saved CSVs and both
   `artifacts/p_test_true_days.npy` and `artifacts/p_test_pred_days.npy` present.
   These arrays are required for the actual-versus-predicted plot and are not
   distributed in the repository.

These steps do not retrain the models. A fresh clone contains notebook outputs,
not the local CSVs and arrays required for this regeneration path.

### Method summary

Two finder networks share the patient and physician latent tables and train
alternately: one side trainable, the other frozen, swapping each cycle. Training
stops at the cycle level with best-cycle restore. The predictor is asymmetric —
patients enter as 54 observed features, physicians as latent traits only.

Hyperparameters are taken unchanged from prior CDLD work and were not tuned for
this dataset. A separate search over learning rate, training length and latent
dimension (15 configurations) moved performance by 0.033 days (0.78%); the one
candidate that passed a prespecified acceptance criterion did not survive a seed repeat,
so the original setting was kept.

## Requirements

Python 3.11, TensorFlow 2.19, scikit-learn, pandas, numpy, scipy, matplotlib,
seaborn, pyarrow. The four-learner comparison additionally needs xgboost,
lightgbm and catboost; the SHAP analysis needs shap.
